## Project Description

Student Dashboard is an interactive data visualization application developed using Python, Streamlit, Pandas, and Plotly.

The purpose of this project is to analyze student performance data and present meaningful insights through interactive charts, graphs, and statistical summaries.

---

## Technologies Used

* Python
* Streamlit
* Pandas
* Plotly
* NumPy

---

## Features

* Student data analysis
* Interactive dashboard
* Data visualization using charts
* Student performance analysis
* Filtering options
* Statistical summaries
* Interactive data exploration

## How to Run Locally

### Install Required Packages

```bash
pip install -r requirements.txt
```

### Run Streamlit Application

```bash
streamlit run app.py
```

The application will run locally at:

```
http://localhost:8501
```
