## Project Description

The Student Dashboard is an interactive data visualization application developed to analyze and visualize student performance data.

The project uses Python-based data analysis and visualization technologies to transform raw student data into meaningful insights through interactive dashboards, charts, and statistical summaries.

The dashboard provides an easy-to-use interface for exploring student information, analyzing academic performance, and understanding data patterns through visual representation.

---

### Python

Used for:

* Application development
* Data processing
* Dashboard logic implementation

Used for:

* Building the interactive web dashboard

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/hasindu-23da2-0150/23DA2-0150_Student_Dashboard.git
```

### 2. Navigate to Project Folder

```bash
cd 23DA2-0150_Student_Dashboard
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Streamlit Application

```bash
streamlit run app.py
```

The application will open in your web browser.

Default URL:

```
http://localhost:8501
```
